# Projects

One project = one folder. Create `index.html` in the folder when you start that project (later add `styles.css` and `script.js`).

| Folder | Project |
| --- | --- |
| `01-about-me/` | About Me page (HTML) |
| `02-fan-page/` | Fan page (CSS) |
| `03-card-gallery/` | Card gallery (layout) |
| `04-joke-button/` | Joke / fact button (JavaScript) |
| `05-clicker-game/` | Tiny clicker game |
| `06-pokedex/` | Live data from the internet |

See the main [README](../README.md) for what to build. See [GIT.md](../GIT.md) for how to save.
